# 测试规范

## TDD

- 新功能：写测试 → 跑红 → 实现 → 跑绿 → 重构
- Bug：写复现测试 → 跑红 → 修代码 → 跑绿 → 全量回归

## 命名

- 格式：`方法_场景_预期`，配合 `@DisplayName` 描述
- 示例：`testRegisterUser_UsernameExists_ShouldThrowException`
- 禁：`test1`、`testXxx` 等模糊命名

## 结构

Given-When-Then：
```java
@Test
void testExample() {
    // Given: 准备数据
    User user = new User();
    user.setUsername("test");

    // When: 执行操作
    UserBO result = userService.createUser(user);

    // Then: 验证
    assertNotNull(result);
    assertEquals("test", result.getUsername());
}
```

## 覆盖范围

每个方法至少覆盖：
- 正常场景（Happy Path）
- 边界条件
- 异常场景

## 数据库测试

演示项目强制 H2 内存数据库，禁用 MySQL/PostgreSQL（除非测试 DB 特定特性）。

依赖：
```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>test</scope>
</dependency>
```

`src/test/resources/application-test.properties`：
```properties
spring.datasource.url=jdbc:h2:mem:testdb;MODE=MySQL;DB_CLOSE_DELAY=-1;DATABASE_TO_UPPER=false
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
spring.jpa.hibernate.ddl-auto=create-drop

spring.sql.init.mode=always
spring.sql.init.schema-locations=classpath:db/schema-h2.sql
```

测试类加 `@ActiveProfiles("test")`，建表脚本放 `src/test/resources/db/schema-h2.sql`。

测试基类：
```java
@SpringBootTest
@ActiveProfiles("test")
@Transactional  // 自动回滚
public abstract class BaseServiceTest {
}
```

### H2 兼容性

DDL 用标准 SQL，避免 MySQL 特定语法：

| 特性 | H2 | 建议 |
|------|----|----|
| AUTO_INCREMENT / PRIMARY KEY / FOREIGN KEY / INDEX | ✅ | 使用 |
| CURRENT_TIMESTAMP / NOW() / TIMESTAMP | ✅ | 使用 |
| COMMENT | ❌ | 避免 |
| ENGINE / CHARSET | ❌ | 避免 |
| ON UPDATE CURRENT_TIMESTAMP | ❌ | 用触发器 |

如需真实 MySQL 脚本：`schema-mysql.sql`（生产）+ `schema-h2.sql`（测试）。

## 断言

```java
// 推荐：assertAll（任一失败仍执行其余）
assertAll(
    () -> assertNotNull(result),
    () -> assertEquals("test", result.getUsername()),
    () -> assertEquals("test@example.com", result.getEmail())
);
```

## 测试数据工厂

```java
class UserTestDataFactory {
    public static User createDefaultUser() {
        User user = new User();
        user.setUsername("testuser");
        user.setEmail("test@example.com");
        return user;
    }
}
```

## 覆盖率目标

| 层 | 目标 |
|----|------|
| Service | ≥80% |
| Controller | ≥70% |
| Dao | ≥60% |
| Util | 100% |

JaCoCo 配置：
```xml
<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>0.8.11</version>
    <executions>
        <execution>
            <goals><goal>prepare-agent</goal></goals>
        </execution>
        <execution>
            <id>report</id>
            <phase>test</phase>
            <goals><goal>report</goal></goals>
        </execution>
    </executions>
</plugin>
```

运行：`mvn clean test jacoco:report`，报告 `target/site/jacoco/index.html`。

## 反模式（禁止）

- 依赖外部环境（真实 DB / 外部 API）
- 测试间有依赖（共享静态变量）
- 不清理数据（不用 `@Transactional` 自动回滚）

## 提交前检查清单

- [ ] `mvn test` 全通过
- [ ] 覆盖率达标
- [ ] 单测使用 H2
- [ ] 命名清晰，加 `@DisplayName`
- [ ] Given-When-Then 结构
- [ ] 覆盖正常/边界/异常
- [ ] 测试相互独立
- [ ] 数据自动清理
- [ ] 无外部依赖、无数据残留
